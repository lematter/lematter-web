# Roadmap

This roadmap outlines the planned direction for lematter-web. It is a living
document and priorities may shift. Items are grouped by horizon rather than
hard dates.

## Now (in progress)

- [x] Next.js 16 App Router scaffold with TypeScript
- [x] Internationalization with next-intl (English default)
- [x] shadcn/ui + Tailwind CSS v4 design system
- [x] Baseline project documentation

## Next (short term)

- [ ] Add Hindi (`hi`) translations and enable the locale
- [ ] Language switcher component
- [ ] Shared layout: header, footer, navigation
- [ ] SEO: metadata, Open Graph, sitemap, robots
- [ ] CI pipeline (lint + build on pull requests)

## Later (medium term)

- [ ] Additional locales beyond English and Hindi
- [ ] Automated testing setup (unit + component)
- [ ] Accessibility audit and fixes
- [ ] Dark mode toggle wired to the shadcn theme
- [ ] Analytics integration

## Exploring (ideas)

- [ ] Content management approach for localized copy
- [ ] Performance budget and monitoring
- [ ] Progressive Web App support
